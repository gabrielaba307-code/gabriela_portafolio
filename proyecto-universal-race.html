Plataforma Hípica · Web + Mobile · UX/UI

Entender la carrera antes de apostar.

Universal Race reúne carreras, participantes y mercados que deben interpretarse con rapidez. El trabajo UX/UI se centró en facilitar la lectura y comparación de alternativas, manteniendo la misma lógica entre desktop y mobile.

Enfoque UX/UI Responsive
01 · La carrera

Cada evento reúne distintas variables.

Antes de realizar una selección, el usuario necesita identificar la carrera, revisar participantes y encontrar las opciones de apuesta que le interesan.

Cuando todos los elementos compiten visualmente, comparar alternativas requiere más esfuerzo.

El diseño debía permitir pasar de una vista general a una decisión específica sin obligar al usuario a memorizar datos entre pantallas.

02 · El reto

Comparar sin depender de la memoria.

El reto no era simplemente mostrar información, sino facilitar la comparación antes de realizar una selección.

01

Carreras consecutivas

Diferenciar con claridad la carrera activa frente a otros eventos disponibles.

02

Comparar participantes

Presentar la información mediante patrones estables que permitan comparar caballos.

03

Encontrar mercados

Acceder a distintas opciones de apuesta sin dar el mismo peso visual a todas.

03 · Arquitectura

De la carrera al mercado.

La navegación sigue el orden natural de análisis: primero el evento, después sus participantes y finalmente las opciones de apuesta.

NIVEL 01

Carrera

Define el evento que se está revisando y funciona como punto de partida.

NIVEL 02

Participantes

Permite revisar y comparar los caballos asociados a la carrera seleccionada.

NIVEL 03

Mercados

Presenta las alternativas de apuesta disponibles para el evento.

04 · Responsive

Las prioridades cambian según la pantalla.

Desktop permite comparar más elementos simultáneamente. Mobile necesita revelar la misma información de una manera más progresiva.

La adaptación no consistió únicamente en reducir componentes, sino en decidir qué debe aparecer primero.

DESKTOP

Comparación simultánea

El espacio horizontal permite mantener más participantes y datos visibles.

MOBILE

Lectura progresiva

El contenido sigue una secuencia vertical y prioriza la siguiente decisión.

ADAPTACIÓN

Referencias compartidas

Carrera, participantes y mercados mantienen una relación reconocible entre dispositivos.

05 · Decisiones UX/UI

Diseñar para comparar.

Las decisiones se enfocaron en reducir el esfuerzo necesario para identificar carreras, comparar participantes y llegar al mercado deseado.

01

Carrera activa reconocible

El evento seleccionado se diferencia visualmente de las demás carreras disponibles.

02

Patrones de participantes

Posiciones y estilos repetidos facilitan la comparación entre alternativas.

03

Lectura agrupada

Los datos relacionados se presentan juntos para facilitar su interpretación.

04

Mercados progresivos

Las alternativas principales reciben prioridad y las adicionales permanecen disponibles.

05

Priorización mobile

El contenido se reorganiza según importancia, no únicamente según su posición en desktop.

06 · Resultado

Mayor claridad para comparar y decidir.

La propuesta establece una secuencia reconocible entre carrera, participantes y mercados, manteniendo esa lógica en web y mobile.

El objetivo no fue mostrar menos información, sino hacerla más fácil de interpretar en el momento en que el usuario la necesita.

01 Secuencia clara entre carrera, participante y mercado.
02 Patrones orientados a facilitar la comparación.
03 Adaptación responsive entre desktop y mobile.
