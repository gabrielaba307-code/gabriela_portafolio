Terminal de apuestas · Hípica · UX/UI

Operar rápido sin perder control.

DoradoBet es una herramienta de trabajo para registrar apuestas desde una terminal. El diseño conecta la búsqueda de una carrera, la selección de participantes y el armado del ticket, reduciendo pasos durante una operación que se repite constantemente.

Rol UX/UI Designer
Producto Terminal de apuestas
Industria Apuestas hípicas
Plataforma Desktop · Terminal
01 · Operación

Cada paso adicional ralentiza la atención.

El operador trabaja mientras atiende a un cliente. Necesita localizar una carrera, registrar selecciones, revisar el ticket y completar la jugada sin cambiar constantemente de vista.

Aquí la velocidad importa, pero también la precisión: una interacción rápida que facilite errores no resuelve el problema.

02 · El reto

Procesar apuestas sin equivocarse.

La terminal debía responder a una dinámica repetitiva donde el operador necesita actuar con rapidez y comprobar cada selección antes del cierre.

01

Encontrar la carrera

Llegar rápidamente al evento solicitado por el cliente.

02

Registrar la selección

Relacionar participante, cuota y carrera para reducir errores durante una operación rápida.

03

Revisar el ticket

Comprobar lo registrado antes de procesar una jugada que puede contener varias selecciones.

03 · Flujo

Una secuencia corta y repetible.

El flujo principal se planteó para minimizar cambios de pantalla entre la solicitud del cliente y el cierre de la jugada.

PASO 01

Carrera

Localizar el evento que se quiere operar.

PASO 02

Selección

Registrar la alternativa solicitada directamente desde la información del evento.

PASO 03

Ticket

Reunir las selecciones y comprobarlas antes de completar la transacción.

04 · Tareas complementarias

Resolver tareas sin romper el flujo.

La terminal también necesita responder a situaciones que aparecen durante la atención, como transmisiones o validaciones de cliente.

Estas funciones deben poder resolverse cuando son necesarias sin obligar al operador a reconstruir la apuesta después.

TRANSMISIONES

Seguir la carrera

Consultar el evento desde el mismo entorno donde se procesa la jugada.

VALIDACIÓN

Resolver una excepción

Atender la validación de un cliente sin convertirla en un recorrido independiente.

TICKET

Revisar antes de cobrar

Mantener las selecciones disponibles hasta completar la transacción.

05 · Decisiones UX/UI

Diseñar para una operación frecuente.

Las decisiones priorizan velocidad de ejecución, reconocimiento y prevención de errores durante tareas repetitivas.

01

Menos cambios de pantalla

Consulta y acción se acercan para reducir desplazamientos innecesarios.

02

Elementos reconocibles

Participantes, cuotas y estados utilizan patrones estables para acelerar la lectura.

03

Ticket como control

Las selecciones permanecen disponibles para revisarlas antes de procesarlas.

04

Acciones prioritarias

Las acciones que hacen avanzar la transacción se diferencian de controles secundarios.

05

Procesos puntuales

Las validaciones aparecen cuando son necesarias sin desplazar permanentemente la tarea principal.

06

Prevención de errores

Antes de confirmar se muestra suficiente información para detectar una selección incorrecta.

06 · Resultado

Una terminal orientada a la ejecución.

La propuesta permite pasar de la carrera al ticket con menos interrupciones y conserva los datos necesarios para comprobar cada jugada antes de procesarla.

DoradoBet se plantea como una herramienta de trabajo donde rapidez y precisión tienen el mismo peso.
